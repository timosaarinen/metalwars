01 / THE LOADOUT

Small kit.
Useful company.

Made for the match you're playing, with a little something for the match you're waiting on.

01

Your kit, in sight.

A movable WSG panel with known-spell cooldown icons for warriors and paladins. Keep the essentials together without rebuilding your interface.

CLASS HELPERS
02

A flag on your mind.

A visible carrier reminder for the decisions that matter. Toggle carrier mode yourself with /mw flag when you want it pinned in view.

FLAG AWARENESS
03

Hold flag. Drop blocks.

Flagstack is a little falling-block game for the lull. It pauses on combat, death, and WSG objective messages, so the battleground gets you back.

Get MetalWars 0.1.0 ↘
01

Download and extract.

Use the Download alpha button. Extract the ZIP to get a single folder named MetalWars.

Use the addon ZIP, not GitHub's “Download ZIP” source archive.

02

Find your Forever installation.

In Battle.net, open the game settings / game directory for WoW Forever. Find that client's Interface/AddOns directory and copy the MetalWars folder inside.

Interface/AddOns/MetalWars/MetalWars.toc

That is the final path to check. Avoid an extra nested MetalWars folder.

03

Enable it, then try it.

Restart the game and enable MetalWars from the character-select AddOns menu. Log in and enter /mw. Use /mw blocks to open Flagstack.

Updating? Close the game and replace the old MetalWars addon folder with the new one.

FIRST TEST

This is a working scaffold, awaiting live-client validation. Try it outside combat first, then check the HUD and automatic game pause in WSG. If something breaks, run /mw status and open an issue with your build and any Lua error.

03 / AT YOUR COMMAND

Keep it simple.

Type these in the in-game chat.

/mw
Toggle the helper panel
/mw blocks
Open or close Flagstack
/mw flag
Toggle your carrier reminder
/mw status
Show client and addon diagnostics
/mw help
Show the command list
